# Yima IDE 自定义 API 版（v1.1.0）

基于 Yima IDE 1.0.8preview 修改的版本。移除了原版内置的积分、登录、账号体系，替换为**完全自定义的 AI 供应商接入**，支持多组参数调节与多档案切换。

## 主要改动

- **去除积分 / 登录 / 账号功能**：无需登录即可使用，移除额度、会员、兑换码等入口。
- **自定义供应商**：可自由填写任意兼容 OpenAI 接口的服务商（Base URL + API Key + 模型）。
- **多供应商档案**：支持保存多组配置档案，随时新建 / 编辑 / 删除 / 一键切换。
- **模型拉取**：从供应商 `/v1/models` 自动获取可用模型列表，也可手动填写。
- **请求参数调节**：max_tokens（最大输出）、top_p（采样）、temperature（温度）、系统提示词。
- **自定义请求头**：按 `Header: Value` 格式逐行填写，注入到所有 API 请求。
- **思考强度适配**：内置关闭 / 低 / 中 / 高预设，支持自定义 `reasoning_effort`。
- **上下文窗口适配**：内置常见厂商预设（如 32K / 64K / 128K / 200K），支持自定义并按窗口自动裁剪历史消息。

## v1.1.0 更新内容

- **实际模型调用替换**：修复真实 API 请求仍回落预设模型的问题，现在请求体 `model` 字段与对话模型选择器均使用自定义模型名。
- **对话模型选择器**：配置自定义模型后，对话界面的模型选择器仅显示自定义模型，不再展示预设模型。
- **账号页面精简**：移除「联系客服 / 建议反馈 / 开源许可」等冗余菜单，仅保留「自定义 API 设置」入口。
- **设置页 UI 统一**：自定义 API 设置页重绘为与 App 一致的 Material3 风格（品牌蓝主题、圆角填充输入框、分区标题、统一按钮样式）。

## 自定义 API 设置入口

启动 App 后，在侧边菜单中点击「**自定义 API 设置」**打开配置对话框：

| 字段 | 说明 |
| --- | --- |
| 档案名称 | 当前配置档案名（用于多档案切换） |
| Base URL | 供应商接口地址，如 `https://api.openai.com`（不含 `/v1`） |
| API Key | 你的密钥 |
| 模型 | 点击「拉取模型」自动获取列表，或手动填写模型名 |
| 温度 / max_tokens / top_p | 采样与输出长度参数 |
| 系统提示词 | 注入到对话首条 system 消息 |
| 自定义请求头 | 每行一个 `Header: Value` |
| 思考强度 / 上下文窗口 | 预设 + 自定义 |

## 安装

```bash
# 卸载原版后安装（签名不同，不可覆盖安装）
adb install -r Yima_Custom_API_v1.1.0.apk
```

或直接拷贝 APK 到手机后点击安装（需允许安装未知来源应用）。Android 14+ 已使用 v3 签名。
