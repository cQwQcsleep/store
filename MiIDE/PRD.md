# MiIDE — 安卓 AI 编程 IDE 产品需求文档（PRD v1.0）

> 状态：已与产品负责人确认核心决策，待实施（M1）
> 更新日期：2026-08-16

---

## 1. 产品概述

**产品名**：MiIDE

**一句话定义**：面向「AI 先尝者」的安卓端 AI 编程 IDE，以 AI 为核心（对话 / 补全 / Agent / MCP），配套轻量代码编辑器与可扩展的完整 IDE 能力（运行、终端、内置浏览器、Git、远程），兼容全部 AI 供应商并支持深度自定义。

**产品形态**：AI 助手优先 + 轻量编辑器（分里程碑扩展为全功能 IDE）。

**市场**：中国大陆优先，V1 仅简体中文 UI（架构预留 i18n）。

**商业模式**：完全免费 + 完全开源 + 零收集零埋点。

**发布渠道**：仅 GitHub Release APK。

**最低系统**：Android 12+（minSdk 31）。

---

## 2. 目标用户

- **AI 先尝者**（主要画像）：以 AI 生成代码为主、自身编码能力其次，希望「一句话让 AI 写出能跑的代码」。
- 次画像：专业开发者的移动端轻量场景（改代码、查 bug、远程运维）。
- 用户技术水平中等，需低学习成本的 onboarding 与预设模板。

---

## 3. 核心卖点（不可妥协）

1. **全供应商兼容 + 深度自定义**
   - OpenAI 兼容统一协议 + 原生协议深度适配 + API 聚合网关 + 逐模型参数化配置。
2. **稳定流畅高性能**
   - 慢响应**自动重试**、多线程 / 多进程、硬件加速、用量轨迹追踪、**上下文缓存优化（高缓存命中率，降本提速）**。
3. **AI 能力闭环**
   - 底部面板 / 全屏对话、幽灵补全（自动 + 手动两种模式）、function calling、**MCP 协议**。
   - **AI 过程可见与可引导**：实时动作流 + 思考可见 + diff 预览 + 跑马灯小窗口；支持中途打断重定向 / 暂停继续 / 建议队列。
4. **轻量全功能**
   - 编辑器 + 内置多语言运行时 + 内置虚拟终端 + **内置浏览器**（预览 / 通用浏览 / AI 抓取 / DevTools）+ Git + 远程 SSH/SFTP（分里程碑落地）。
5. **隐私安全**
   - API Key Keystore 加密存储、零遥测零埋点、完全免费开源。

## 4. 功能范围与里程碑

### M1 — 核心闭环
- 项目骨架（Gradle / 模块化 / Compose / 主题体系）
- 代码编辑器（Rosemoe CodeEditor：高亮 / 行号 / 折叠）
- 文件管理与多项目切换
- AI 对话（底部面板 + 全屏两种形态）
- 供应商接入：OpenAI 兼容协议 + 自定义供应商（参数化模型配置）
- 慢响应自动重试机制
- 用量轨迹追踪（请求耗时 / token / 费用）
- HyperOS 风格基础主题（深/浅色、动态取色）
- API Key 管理（Keystore 加密存储、多 Key、按项目隔离）

### M2 — AI 增强
- 幽灵补全（自动触发 + 手动触发两种模式）
- function calling + MCP 客户端
- 内置精简运行时：Python（Chaquopy）+ JS（QuickJS）+ Lua（LuaJ），Ruby/C 等评估后扩展
- 内置虚拟终端（Termux 可选增强）
- AI 生成代码「一键运行」闭环
- 上下文缓存 / 提示词缓存优化（提升缓存命中率）
- **内置浏览器**（四项能力）：
  - 网页实时预览：编辑 HTML/CSS/JS 时分屏/面板实时渲染；
  - 通用浏览器标签：多标签浏览文档 / 搜索 / 打开链接；
  - AI 网页抓取：AI 对话内抓取 URL 内容摘要与页面预览；
  - DevTools 调试：Console / DOM / 网络请求查看与调试。
- **AI 过程可见（看得见在干嘛，防发呆）**：
  - 实时动作流：正在读哪个文件 / 搜索什么 / 编辑哪行 / 运行什么命令（现场直播式）；
  - 思考过程可见：reasoning 内容实时展示，知道 AI 为什么这么做；
  - 改动 diff 预览：改动前展示将改什么，可接受 / 拒绝；
  - 耗时 / token 消耗显示，进度可感知；
  - **跑马灯小窗口**：AI 全部输出都在这里实时滚过一遍，用户随时瞄一眼即可掌握动态。
- **AI 引导（AI 工作时可发修改意见）**：
  - 中途打断并重定向：发指令立即响应（如「别改 A，先改 B」「换个方案」）；
  - 暂停 / 继续控制：先看完现状再决定是否继续；
  - 建议队列（非阻塞）：不打断 AI，把意见排入队列，本轮结束后再处理。

### M3 — 完整 IDE
- Git 集成（clone / commit / push / pull / branch / diff）
- 国内主流供应商深度适配（DeepSeek / 智谱 GLM / Kimi / 通义千问等）
- API 聚合网关（多 Key 轮询 / 失败切换 / 路由 / 限额）
- 分屏多窗格（编辑 + 对话、编辑 + 终端）
- 远程 SSH / SFTP 开发
- 完整插件市场（基础版：脚本插件 / 主题 / 官方功能包）
- LSP 评估与可选引入
- 正式发布（GitHub Release）

## 5. AI 供应商架构（差异化核心）

### 5.1 分层设计

```
┌────────────────────────────────────────────────────┐
│             Provider 抽象层（Adapter 接口）           │
│  chat() / stream() / models() / tools() / caps()   │
└──────┬──────────────────────────┬──────────────────┘
       │                          │
┌──────▼────────┐        ┌────────▼────────────────┐
│  内置适配器     │        │  用户自定义供应商模板     │
│ · OpenAI 兼容 │        │ · JSON 定义请求/响应映射  │
│ · DeepSeek    │        │ · baseUrl / 鉴权方式     │
│ · 智谱 GLM    │        │ · 协议/路径/字段自定义    │
│ · Kimi/Moonshot│       │ · 任意三方聚合商          │
│ · 通义千问     │        └────────┬────────────────┘
│ · Anthropic  │                 │
│ · Gemini      │                 │
└──────┬────────┘                 │
       └─────────────┬────────────┘
               ┌──────▼──────────┐
               │     聚合网关     │
               │ 多Key轮询/失败   │
               │ 切换/路由/限额   │
               └──────┬──────────┘
               ┌──────▼──────────┐
               │  参数化模型配置   │ ★ 核心
               │ 逐模型可调：     │
               │ · 思考强度       │
               │ · 上下文窗口     │
               │ · max_tokens    │
               │ · temperature   │
               │ · topP/多模态   │
               │ · 工具开关       │
               │ · 上下文缓存     │
               └─────────────────┘
```

### 5.2 关键要求

- **参数化模型配置**：每个模型是独立配置项，包含但不限于 `baseUrl`、`apiKey`、`contextWindow`、`maxTokens`、`reasoningEffort（思考强度）`、`temperature`、`topP`、`toolsEnabled`、`multimodal`、`cacheEnabled`、`pricing`。
- **自定义供应商模板**：用户可通过 JSON 模板定义请求/响应映射，适配任意 OpenAI 兼容三方（例如一家聚合商同时提供 DeepSeek + GLM-5.2，可逐模型调整思考强度与上下文窗口）。
- **聚合网关**：多 Key 轮询、失败自动切换、按模型路由、额度/限额控制。
- **性能与可靠性**：
  - 慢响应自动重试（指数退避 + 超时控制）；
  - 多线程 / 多进程任务调度、硬件加速（后台任务、GPU 可用时）；
  - **上下文缓存 / 提示词缓存**：复用历史 token，提升缓存命中率以降低延迟与成本；
  - **用量轨迹追踪**：记录每次请求的耗时、token、费用，提供用量统计面板。
- **能力探测**：自动拉取模型列表、上下文长度、工具 / 多模态能力。
- **MCP**：支持 Model Context Protocol 作为工具扩展通道。

## 6. 技术栈

| 层面 | 选型 |
|---|---|
| 语言 / UI | Kotlin + Jetpack Compose（M3 基础 + HyperOS 品牌化定制） |
| 编辑器内核 | Rosemoe CodeEditor（高亮 / 行号 / 折叠 / 幽灵补全渲染） |
| 依赖注入 | Hilt |
| 网络 | Ktor |
| 本地存储 | Room |
| 运行时 | Python（Chaquopy）+ JS（QuickJS）+ Lua（LuaJ），后续评估更多 |
| 终端 | 内置虚拟终端（Termux 可选增强） |
| 内置浏览器 | Android WebView（预览 / 通用浏览 / AI 抓取）+ DevTools 调试（Console / DOM / 网络） |
| Git | JGit / 内置实现 |
| minSdk / target | minSdk 31，target 最新稳定版 |
| 构建 | Gradle（Kotlin DSL）+ 模块化架构 |

## 7. UI / UX 设计

- **视觉方向**：Material 3 为基础 + **HyperOS 风格**品牌化定制——大圆角、柔和阴影、渐变高光、毛玻璃质感、灵动过渡。
- **信息架构**：
  - 底部导航：文件 / 编辑 / 运行 / 设置；
  - AI 对话：底部可收起面板，点开全屏对话；
  - AI 工作台：**跑马灯小窗口**（AI 全部输出实时滚过）+ 动作流 / 思考可见 / diff 预览 / 打断·暂停·建议入口；
  - 内置浏览器：通用浏览器标签页 + 网页预览面板（编辑 HTML 时可分屏预览）；
  - 分屏多窗格：M3 落地（编辑 + 对话、编辑 + 终端、编辑 + 网页预览）。
- **系统要求**：edge-to-edge、预测性返回、动态取色（Material You）、单手可及的主操作、空/加载/错误状态完备。
- **补全交互**：幽灵补全（自动触发 + Tab 接受）+ 对话生成补全（手动复制/插入），两种模式并存。
- **多语言**：V1 仅中文，架构预留 i18n。

## 8. 数据与安全

- API Key：Android Keystore 加密存储；支持多 Key、按项目隔离。
- 项目存储：应用沙箱 + SAF 用户自选目录。
- 聊天 / AI 历史：本地保存，支持搜索与导出（Markdown / JSON）。
- 云同步：**不做自建云同步**，跨设备靠 Git。
- 隐私：零收集、零埋点、零遥测，代码内容全本地。
- 网络：支持代理配置（HTTP / SOCKS5）。

## 11. 验收标准（各里程碑）

- **M1 完成**：可安装运行；创建项目、编辑/保存文件；接入任意 OpenAI 兼容供应商并自定义参数化模型；AI 对话可用；慢响应自动重试生效；用量轨迹有记录；HyperOS 主题可用。
- **M2 完成**：幽灵补全与对话补全可用；function calling 与至少一个 MCP 工具端到端打通；内置 Python/JS/Lua 运行「一键运行」AI 生成代码；虚拟终端可用；上下文缓存命中率有可观测提升；内置浏览器四项能力可用（HTML 实时预览、多标签浏览、AI URL 抓取、DevTools 调试）；AI 过程可见可用（实时动作流、思考可见、diff 预览、耗时/token、跑马灯小窗口）；AI 引导可用（中途打断重定向、暂停/继续、建议队列）。
- **M3 完成**：Git 常用操作可用；DeepSeek/智谱 GLM/Kimi/通义千问深度适配；聚合网关多 Key 切换；分屏多窗格；远程 SSH/SFTP；插件市场可安装至少一个插件；正式发布 GitHub Release。

## 12. 风险与未决事项

| 事项 | 说明 | 状态 |
|---|---|---|
| 内置运行时选型 | Python/JS/Lua 确定；Ruby/C 等需评估体积与可行性 | 部分未决 |
| 多进程方案 | 虚拟终端 / 运行时是否独立进程，需在 M2 定 | 未决 |
| 插件市场安全模型 | 沙箱与权限模型需细化 | 未决 |
| 开源协议 | 实施前确定 | 未决 |
| LSP | M2/M3 评估，倾向不优先 | 已定（后期再加） |
| 上下文缓存实现 | 依赖具体供应商缓存接口（如 Anthropic prompt caching / DeepSeek 缓存） | 需在 M2 细化 |
| 聚合网关限额 | 是否需要用户侧额度/预算上限控制 | 未决 |
| 浏览器 DevTools 深度 | Android WebView 调试能力受限，需评估 CDP/注入方案与功能边界 | 需在 M2 细化 |
